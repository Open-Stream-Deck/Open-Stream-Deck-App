# Установка

Установщики лежат в [последнем релизе](https://github.com/Open-Stream-Deck/Open-Stream-Deck-App/releases/latest). Установка, обновление и удаление работают через [Velopack](https://velopack.io). При каждом запуске сначала открывается маленькое окно: оно проверяет новую версию, скачивает и ставит её, если она есть, и только потом открывает приложение. Отключить это можно в «Настройки», «Приложение», «Обновления», там же есть ручная проверка.

## Windows

Нужны Windows 10 или 11 x64. Скачайте `OpenStreamDeck-win-Setup.exe` и запустите. Установка проходит в один клик без вопросов: окно с прогрессом, затем приложение открывается само. Ставится в `%LocalAppData%\OpenStreamDeck`, права администратора не нужны, ярлыки появляются на рабочем столе и в меню «Пуск». Если в системе нет WebView2, установщик поставит его сам.

Удаление: «Параметры», «Приложения», Open Stream Deck, «Удалить». Настройки и профили лежат отдельно и после удаления остаются.

SmartScreen может показать «Windows защитила ваш компьютер», потому что у установщика нет сертификата подписи. Нажмите «Подробнее» и «Выполнить в любом случае».

## macOS

Нужна macOS 11 или новее, подходят и Apple Silicon, и Intel. Скачайте `OpenStreamDeck-osx-Setup.pkg` и откройте. Установщик спросит, куда ставить: в «Программы» для всех или в `~/Applications` только для себя. После установки приложение откроется само.

Установщик не подписан сертификатом Apple, поэтому macOS сначала его заблокирует. Откройте «Системные настройки», «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и запустите `.pkg` ещё раз.

Удаление: перетащите Open Stream Deck из «Программ» в Корзину.

Горячим клавишам, вводу текста, медиаклавишам и блокировке экрана нужно разрешение: «Конфиденциальность и безопасность», «Универсальный доступ», включите Open Stream Deck. После обновления macOS может перестать считать разрешение действующим, тогда выключите его и включите снова.

## Linux

Нужен x64 и дистрибутив не старше Ubuntu 22.04: Ubuntu, Linux Mint 21+, Pop!_OS, Debian 12+, Fedora 38+, Arch и производные.

AppImage нужен FUSE 2, на многих системах его нет из коробки:

| Система | Команда |
| --- | --- |
| Ubuntu 24.04 и новее, Mint 22 | `sudo apt install libfuse2t64` |
| Ubuntu 22.04, Mint 21, Debian | `sudo apt install libfuse2` |
| Fedora | `sudo dnf install fuse-libs` |
| Arch | `sudo pacman -S fuse2` |

Скачайте `OpenStreamDeck.AppImage` и положите куда удобно, например в домашнюю папку. Затем разрешите запуск: правый клик по файлу, «Свойства», включите «Разрешить запуск как программу», и откройте его двойным кликом. То же из терминала:

```bash
chmod +x OpenStreamDeck.AppImage
./OpenStreamDeck.AppImage
```

Значок в трее в GNOME виден только с расширением AppIndicator. В Ubuntu оно стоит по умолчанию, в Debian и Fedora поставьте `gnome-shell-extension-appindicator`.

При первом запуске приложение попросит пароль, чтобы поставить правило udev: оно даёт доступ к деке без root. После этого переподключите деку. Если отказались, правило можно поставить руками:

```bash
sudo tee /etc/udev/rules.d/70-open-stream-deck.rules > /dev/null <<'EOF'
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1209", ATTRS{idProduct}=="0001", TAG+="uaccess"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="0300", ATTRS{idProduct}=="1020", TAG+="uaccess"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="eeef", ATTRS{idProduct}=="2929", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules
sudo udevadm trigger
```

Обновления заменяют сам файл AppImage. Удаление: удалите файл.

Горячие клавиши, ввод текста и медиаклавиши идут через X11. В сессии Wayland они доходят только до программ, запущенных через XWayland. Блокировка экрана вызывает `loginctl lock-session`, а если он недоступен, `xdg-screensaver lock`.

## Прошивка

Со стоковой прошивкой приложение деку видит, но управлять ею не может. Скачайте BIN-файл из [релизов прошивки](https://github.com/Open-Stream-Deck/Firmware-AjazzAKP153R/releases), откройте «Настройки», «Прошивка», нажмите «Выбрать файл» и «Установить». Когда приложение попросит, переподключите USB.
